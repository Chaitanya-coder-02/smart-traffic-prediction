# SmartFlow — Smart Traffic Prediction System

> **Educational ML Project** — Predicts hourly traffic volume on Interstate 94 (Minnesota, USA) using historical weather and traffic data, and visualizes results in an interactive 3D smart city.

---

## Architecture

```
User Input (React form)
       │
       ▼
Flask REST API  (/api/predict)
       │
       ▼
Trained sklearn Pipeline
  ├── ColumnTransformer (impute → scale → encode)
  └── RandomForest / LinearRegression / Dummy
       │
       ▼
Predicted Volume (veh/hr) + Congestion Category
       │
       ├──▶ Dashboard stats & charts (Recharts)
       └──▶ 3D City scene (React Three Fiber — car speed/density)
```

## Dataset Setup

1. Go to: https://www.kaggle.com/datasets/ramyahr/metro-interstate-traffic-volume
2. Download and extract the ZIP file
3. Place the CSV at:
   ```
   smart-traffic-prediction/data/Metro_Interstate_Traffic_Volume.csv
   ```

> ⚠️ The application will show a clear error if the CSV is missing — it will never silently substitute fake data.

## Backend Setup (Windows PowerShell)

```powershell
# 1 — Navigate to project root
cd smart-traffic-prediction

# 2 — Create virtual environment
python -m venv venv

# 3 — Activate virtual environment
.\venv\Scripts\Activate.ps1

# 4 — Install dependencies
pip install -r backend/requirements.txt

# 5 — Copy env file
Copy-Item backend\.env.example backend\.env

# 6 — Train the model (requires dataset in data/)
python backend/train.py

# 7 — Start Flask API
python backend/app.py
```

API is now available at: `http://localhost:5000`

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/health` | Backend + model status |
| GET | `/api/dashboard` | Metrics, stats, summaries |
| POST | `/api/predict` | Traffic volume prediction |
| GET | `/api/analytics/hourly` | Avg volume by hour |
| GET | `/api/analytics/weekly` | Avg volume by weekday |
| GET | `/api/model/metrics` | Evaluation metrics |
| GET | `/api/analytics/feature-importance` | Feature importances |
| GET | `/api/analytics/actuals-vs-predicted` | Test set results |

### Example Prediction Request

```bash
curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "date_str": "2024-07-15",
    "hour": 8,
    "temp": 22.0,
    "rain_1h": 0.0,
    "snow_1h": 0.0,
    "clouds_all": 20,
    "weather_main": "Clear",
    "is_holiday": 0
  }'
```

### Example Response

```json
{
  "predicted_volume": 4823.5,
  "congestion_category": "High",
  "congestion_color": "#f97316",
  "model_name": "RandomForest",
  "input_echo": { "hour": 8, "weather_main": "Clear", ... },
  "prediction_note": "ML prediction from I-94 Minnesota model. Not a live reading."
}
```

## Congestion Thresholds

| Level | Range | Color |
|-------|-------|-------|
| Low | 0 – 2,000 veh/hr | 🟢 Green |
| Moderate | 2,000 – 4,000 veh/hr | 🟡 Yellow |
| High | 4,000 – 5,500 veh/hr | 🟠 Orange |
| Very High | > 5,500 veh/hr | 🔴 Red |

> These are illustrative thresholds derived from the I-94 dataset. Actual congestion also depends on lane count, incidents, and vehicle mix.

---

## Model Evaluation Methodology

- **Split**: Chronological 80/20 — older records train, newer records test. No temporal data leakage.
- **Preprocessing**: Fit only on training data, applied to test data.
- **Metrics**: MAE, RMSE (vehicles/hour), R² — regression metrics, NOT classification accuracy.
- **Selection**: Best model by test RMSE.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `[SETUP ERROR] Dataset not found` | Place CSV at `data/Metro_Interstate_Traffic_Volume.csv` |
| `Model not loaded` | Run `python backend/train.py` first |
| `Cannot reach backend` | Start Flask: `python backend/app.py` |
| `CORS error` | Check `CORS_ORIGINS` in `backend/.env` matches your frontend URL |
| `pandas install fails` | Upgrade pip: `pip install --upgrade pip`, then retry |
